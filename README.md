# Walmart Marketplace Operations

A practical framework for **Walmart Marketplace item setup, catalog management, attribute mapping, variants, listing quality, and troubleshooting**.

## Included Files
- [Attribute Mapping Template](attribute_mapping_template.csv)
- [Listing Quality Audit](listing_quality_audit.md)

## Workflow
1. Collect and normalize source product data.
2. Select the correct product type/category.
3. Map source fields to Walmart attributes.
4. Validate required and recommended fields.
5. Review identifiers and variants.
6. Upload a controlled test set.
7. Diagnose processing errors.
8. Correct the source data and re-upload.
9. Verify the live item.

## Listing Quality Checklist
- Product name is clear and accurate
- Key features are complete
- Description is useful and readable
- Required attributes are populated
- Variant values are consistent
- Images match the actual product
- Published content is reviewed after processing
